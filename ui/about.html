About the Converter

Amharic (Soba Harari) → Latin Harari transliteration

⚡ 100% local · Python backend

What is this? A neo‑brutalist web app that converts Amharic text (specifically the Harari dialect, also known as Soba Harari) into a Latin‑based phonetic representation. Perfect for language learners, linguists, or anyone who needs to read Harari in Latin script.

How it works – The transliteration is handled by a local Python backend (Eel framework). No data leaves your machine: privacy‑first, offline ready.

Features – Real‑time character count, one‑click copy, example text, and a bold, responsive interface with 15px rounded corners. The navigation bar follows Ubuntu‑style icons: hover over any icon to see the menu name.

Tech stack
  • Frontend: HTML5, CSS3 (Neo‑brutalist), vanilla JavaScript
  • Backend: Python + Eel (bridges Python and web)
  • Transliteration: custom Python mapping for Harari syllables
